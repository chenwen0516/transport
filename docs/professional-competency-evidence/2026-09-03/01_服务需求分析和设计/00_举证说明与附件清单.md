# 服务需求分析和设计举证

## 举证文字说明

本人负责健康助手全双工实时语音交互及 KooSearch 知识库检索相关需求的分析和技术方案设计。

在全双工项目中，针对背景人声误触发、真实用户打断被压制、短附和被识别为新问题、自然停顿被错误结束以及模型空响应等问题，将需求拆解为 WebRTC 实时通信、VAD、流式 ASR、轮次检测、说话人识别、Agent 状态管理和 TTS 播放控制等子能力。基于 LiveKit 及微服务架构，完成全双工总体架构、MMI-TD 轮次检测和 Realtime API 设计，明确 Frontend、Manager、LiveKit Server、Agent Worker、ASR、LLM/VLM 和 TTS 等组件边界、数据流及接口契约。设计 Shadow-first 灰度策略、状态机、幂等控制、决策超时、Fail-safe、单会话降级和 OFF 快速回退机制，保障系统韧性、可靠性和可用性。

在 KooSearch 项目中，围绕 Versatile 面向开发者提供 RAG 能力的场景，分析知识库分片数量对检索效果、上下文完整性和成本的影响，参与设计“长文本开关”和“小召大”检索策略，明确知识库配置、搜索接口参数传递及检索服务生效逻辑。同时梳理文档名称长度、特殊字符等校验规则，以及记忆索引、记忆数据、Metadata 过滤、Threshold、鉴权和错误码等接口契约，形成可落地的需求和技术方案。
