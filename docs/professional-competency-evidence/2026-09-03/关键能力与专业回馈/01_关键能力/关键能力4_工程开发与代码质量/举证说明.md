# 关键能力4：工程开发与代码质量

## 举证说明

本人完成 WebRTC Realtime API、MMI-TD 轮次控制、真实语音 E2E 及多套音频评测工具的代码开发。核心功能包括统一状态机、打断快速路径、Backchannel 规则、自然停顿保护、SpeakerGate 判决回流、幂等控制、迟到事件隔离、超时降级和空响应恢复。

GitHub 远端历史可追溯到本人自 2026 年 5 月以来的 74 个非合并提交，涵盖 Full-Duplex-Bench、WebRTC E2E、BigBench Audio、OpenAudioBench、VoiceBench、MMI Active 和 AA-FDB Badcase 修复等工作。本地 Git 合并历史可核实 8 个全双工主线或集成发布相关 PR：#401、#402、#403、#405、#421、#422、#423、#424。MMI Active 最新远端提交为 `0f8bf9b`。

在 KooSearch 项目中，围绕长文本检索、文档名称校验、记忆索引、Metadata 过滤、Threshold、得分返回、IAM 鉴权、接口流控和第三方模型适配等功能完成代码开发和缺陷修复，形成 10 个可追溯 MR。开发过程中同步关注接口兼容性、异常处理、代码可读性和可测试性，并使用自动化测试和固定样本回归验证代码修改。
