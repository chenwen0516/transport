# 关键能力2：架构与方案设计

## 举证说明

本人基于 LiveKit 和微服务架构完成健康助手全双工总体架构、MMI-TD 轮次检测及 WebRTC Realtime API 设计，明确 Frontend、Manager、LiveKit Server、Agent Worker、ASR、LLM/VLM 和 TTS 等组件边界、部署关系、核心数据流及接口契约。

在轮次控制方面，设计统一输入输出协议、插件化 Detector、Endpointing Policy、Interruption Policy 和运行状态机；将 VAD、流式 ASR、Agent 状态、TTS 播放状态、语义意图和说话人判定纳入统一决策。对 LiveKit 原生控制、Shadow 旁路验证和 Active 独占控制方案进行比较，最终采用 Shadow-first、固定分桶和分阶段灰度方案。

针对系统韧性和可靠性，设计决策超时、Fail-safe、幂等控制、迟到事件隔离、单会话降级、故障阻断和 OFF 快速回退机制；针对接口稳定性，将音频 Media Track 与 DataChannel 事件协议解耦，覆盖会话创建、配置更新、输入转写、回复字幕、回复完成、取消及状态变化等事件。
