# 专业回馈3：质量方法与流程改进

## 举证说明

本人建立“基线测量—日志关联—根因分析—定向修复—固定样本回归—全量验证”的质量闭环，使用固定 Manifest 保证优化前后样本一致，先进行单问题和小规模定向回归，再进行 Canary 和全量验证，避免通过更换样本掩盖问题。

在指标管理方面，区分 MMI 内部处理延迟与包含 ASR、模型、TTS、RTC 的端到端延迟，区分本地代理分与正式榜单分，并同步呈现优化收益和回归风险。在发布流程中引入 Shadow 旁路、小流量 Active Canary、分级灰度和快速回退机制，同时设置重复提交、会话卡死、误打断和延迟恶化等阻断条件，未达到门禁要求的版本不扩大灰度。
